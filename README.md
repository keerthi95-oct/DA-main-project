# DA-main-project
# Project Title

**Product Sales by Region – Sales Performance Analysis**

---

# Objective (Problem Statement)

1. To identify meaningful patterns, trends, and insights from sales data using Exploratory Data Analysis (EDA).
2. To clean, transform, and preprocess the sales data for accurate analysis.
3. To create meaningful visualizations that explain product, regional, and customer sales performance.
4. To provide actionable insights and recommendations to improve sales and business decision-making.

---

# Outcome

The project helps identify **sales trends, top-performing products, regional performance, customer purchasing patterns, discounts, promotions, returns, and payment preferences**. The analysis provides evidence-based insights that can support better sales planning and business decisions.

---

# Domain

**Retail / Sales**

---

# Dataset Information

**Source:** Excelx – Sample Retail Sales Data
**Link:** https://excelx.com/practice-data/sales-retail/

**Dataset Size:** 1,500 sales transaction records

**Year / Timeline:** January 2023 to June 2025

### Dataset Column / Features Description

* **Date** – Date associated with the sales transaction.
* **Region** – Region where the sale was made.
* **Product** – Product sold to the customer.
* **Quantity** – Number of units purchased in the transaction.
* **Unit Price** – Price of one unit of the product.
* **Store Location** – Store where the transaction took place.
* **Customer Type** – Type of customer, such as Retail or Wholesale.
* **Discount** – Discount applied to the transaction.
* **Salesperson** – Salesperson responsible for the transaction.
* **Total Price** – Total value of the transaction.
* **Payment Method** – Method used by the customer for payment.
* **Promotion** – Promotion applied to the sale.
* **Returned** – Indicates whether the product/order was returned.
* **Order ID** – Unique identification number for each order.
* **Customer Name** – Name of the customer.
* **Shipping Cost** – Cost associated with shipping the order.
* **Order Date** – Date on which the order was placed.
* **Delivery Date** – Date on which the order was delivered.
* **Region Manager** – Manager responsible for the respective region.
